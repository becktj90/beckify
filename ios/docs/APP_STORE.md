**Promotional text (170 characters, optional):**
Field jobsite tools and a Toolkit for basics and bench. Shareable engineer plots. Design aid — not a PE stamp or calibrated instrument.

**Description:**

Beckify is a professional field electrical toolbox for engineers, technicians, and students. It is a native iPhone and iPad app, not a website wrapper and not a project gallery. The home screen is two areas: **Field** (jobsite tools, opens first) and **Toolkit** (basics, bench, and references). Search covers both and shows which area a result belongs to.

Field — jobsite calculators, wizards, and instruments. Field home (not while searching) includes a Pinned strip: an editable avatar row of favorites (defaults: Voltage Drop, Wire Size & Ampacity, Motor FLA, Receptacle Selector, Wi-Fi Path, Conduit Fill). Pin Spanish Translator or any tool from a shelf or search.

Field:

• Voltage Drop — code follows Settings. NEC (default) is K-factor VD with parallels, target %, ampacity check, and optional ampacity→VD handoff. 1Ø and 3Ø also show a NEC 2023 Table 250.122 equipment grounding conductor from the next standard OCPD. AS/NZS uses metric sizes, a resistance-only drop (IEC 60228 maximum R, reactance omitted — not AS/NZS 3008 mV/A·m), Clause 3.6.2’s 5% limit, and a Table 5.1 copper earth. AS/NZS current-carrying capacity is not checked. Design aid; confirm the standard / AHJ; not a PE or AEE stamp.
• Conductor Cost Optimizer — compares compliant sizes and parallel runs using a default planning book ($/kft) with per-line or uniform overrides and optional I²R energy. Opt-in Include recommended EGC adds one NEC 2023 Table 250.122 ground per run into first-cost and suggested EMT. Planning allowance only — not LME or a bid. Design aid; confirm Code / AHJ.
• Conductor Length by Resistance — estimate length from a milliohm (mΩ) reading, end-to-end or short-to-parallel, with copper/aluminum temperature compensation, AWG/kcmil or custom circular mils, and estimated copper or aluminum weight (book lb/kft × one-way length, not a scale reading)
• Conduit fill — same-size or mixed conductor sizes; Chapter 9 Table 1 vs Table 4 raceways and Table 5 areas (EMT, IMC, RMC, PVC, ENT, FMC, LFMC). EMT 2½ in and larger use the current Table 4 bores. A generated cross-section draws the wall, each conductor to scale (settled packing, copper core), ID / OD / wire OD / free-area callouts, a fill bar against the nipple or longer-run limit, and an optional Reference Library phase tint. Share saves a PNG. Pinch to zoom. The drawing is illustrative — Table 1 is not a jam check. Insulation names stay on a full-width row. 1Ø, multiwire, or 3Ø plus amps shows the NEC 2023 Table 250.122 size; it is counted only if Count EGC is on. When Settings is AS/NZS, Appendix C C6.2 (50% / 33% / 40%) is shown as guidance and the pass/fail stays NEC. Metric bores are not listed. NEMA 250 and IP notes describe the enclosure, not a number assigned to the raceway.
• Equipment Grounding — Field, next to Conduit Fill. Dedicated NEC 2023 Table 250.122 minimum equipment grounding conductor from the OCPD rating (or the next standard device when you enter load current only), copper or aluminum, optional ungrounded size for the 250.122(A) cap and 250.122(B) note. Not Table 250.66. AS/NZS earth sizing is not in this tool — the screen says it is still showing NEC and Voltage Drop keeps Table 5.1. Panel Directory shows the copper feeder EGC from the main rating. Cable Schedule can show the same row for power cables when you enter an OCPD. Design aid; confirm the Code and the AHJ.
• Flexible Cable Ampacity — Field, next to Conduit Fill and Equipment Grounding. Type W and SO / SJO / STO portable cord from NEC Table 400.5(A)(1) and the 90°C column of Table 400.5(A)(2), with a size pick up to 400 A. Each row names its table. THHN in conduit stays on Wire Size & Ampacity. Install notes say when a cord grip, a raceway, or a NEMA/IP enclosure matters, and they do not assign an enclosure number. Aluminum and Type W 60/75°C cells are not invented. Planning aid; the AHJ and the manufacturer prevail.
• Cable Ladder — Field, next to Conduit Fill. NEC Article 392 tray fill (ladder, ventilated trough, solid bottom, or channel), a NEMA VE 1 hanger check at your span, and a cross-section plus elevation. AWG rows use Chapter 9 Table 5; jacketed cable uses the overall diameter you enter. Optional circle tints follow Reference Library phase, neutral, and EGC color names and are a legend only. NEMA 250, IP wording, and the conduit chip describe the box and the drop, not a listing of the open tray. Planning estimate — verify the manufacturer load table and the AHJ. Not a PE stamp. AS/NZS cable-tray rules are not in this tool.
• Motor full-load current from NEC Tables 430.248 and 430.250

## Cellular App Store limitation (honest)

Public iOS APIs do **not** provide cellular RSRP, RSRQ, SINR, RSSI, or dBm to third-party apps. `CTTelephonyNetworkInfo.serviceCurrentRadioAccessTechnology` reports RAT strings (`CTRadioAccessTechnologyNR`, `LTE`, …). `dataServiceIdentifier` marks the data SIM. `serviceSubscriberCellularProviders` still returns `CTCarrier` fields (name, MCC, MNC, ISO country, `allowsVOIP`) but **CTCarrier is deprecated as of iOS 16 with no public replacement** — values may be empty. `NWPathMonitor` (default and `requiredInterfaceType: .cellular`) reports path status, `usesCellular`, expensive/constrained, interface names, and IPv4/IPv6/DNS support. `CTCellularData` reports whether the app’s cellular data is restricted. Complementary **link quality (RTT)** is TCP connect time while the default path uses cellular — not ICMP ping, not RSRP. Color arc gauges map **radio generation** (2G…5G from RAT) and measured TCP **RTT milliseconds** only — never fabricated RSRP. Do not add private APIs or status-bar scraping to fake a field-strength meter.

## Wi-Fi App Store limitation (honest)

Public iOS APIs do **not** provide Wi-Fi RSSI or dBm to third-party apps (Apple DTS). **Online / Captive** is an HTTP GET to `captive.apple.com/hotspot-detect.html` over Network.framework TCP (not URLSession cleartext, so no ATS exception). A `Success` body is “no captive portal”; a redirect or login HTML is “captive portal”; a satisfied path that cannot reach the host is “local only.” Optional local IPv4 is the probe connection’s `localEndpoint` when it is IPv4 — not a public-IP service and not RSSI. `NWPathMonitor` reports path status; interface names stay behind Advanced path. `NEHotspotNetwork.fetchCurrent` may return SSID/BSSID and a **0.0–1.0** `signalStrength` after location (and Access Wi-Fi Information on a signed team). That 0–1 value is often 0.0; it is not calibrated dBm and is shown as percent/bars only. The in-app heatmap sketches Apple’s 0–1 strength versus GPS or a tapped floor plan. Complementary **link quality (RTT)** is TCP connect time (refused RST still counts) to `NWPath.gateways` or a user-chosen host — not ICMP ping, which App Store apps cannot send. A LAN/gateway target may show the Local Network prompt; without that permission the probe fails honestly. Online / Captive to Apple’s public host does not need Local Network. iOS does not always publish a gateway. Do not add private APIs to fake a dBm meter. On a Mac with a paid team, optionally add the **Access Wi-Fi Information** capability if SSID is empty in review devices. Catalog **Look Check** is a separate photo tool and is not this probe.
