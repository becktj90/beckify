No custom URL yet. If the Beckify API base is injected at deploy, that proxy will be used. Otherwise Read Schedule stays on-device.

Photograph the directory / label only. This tool reads the printed circuit directory or schedule card on the panel door — not the live interior of an open panel. Keep the door closed if you can.
